# Ecloud 首版后端对接清单

请提供接口文档、联调环境和可复现的会话与数据样例。每项接口请说明请求参数、鉴权、响应、错误码，以及重试是否会重复执行。依据 Figma 首版说明和用户最新确认，保存及访问网盘沿用自动游客会话，用户直接操作。 [Figma 首版产品说明](https://www.figma.com/design/LbCyJ0BI2CUGKzjw5fBTgD/LT-%E5%AF%B9%E6%8E%A5-UI?node-id=411-8103) · [首版实施清单](Ecloud-首版产品说明与实施清单.md)

## 1. 游客身份与分享链接

- 请确认如何以现有游客会话令牌鉴权，将云盘文件和用量绑定到服务端解析出的游客 `userId`。提供令牌有效期、自动续会话的方法、会话恢复后的身份连续性，以及到期期间的错误响应。客户端传入的 `userId` 仅用于匹配，所有权以服务端凭证为准。
- 请确认同一设备重装、换机时，原网盘是继续可用还是随游客身份变化，以及可用时如何安全恢复归属。若恢复 Apple 购买只能恢复订阅权益，请说明订阅与旧云文件的授权分别如何处理。
- 提供分享域名、链接格式、有效链接及过期或撤销样例。外部链接唤起 App 和 App 内搜索框粘贴链接，应解析为同一个资源列表。请提供 Universal Link 的域名关联文件（AASA）、对应的 App 标识及路径范围。首版只接收已有分享链接。
- 提供分享根目录、下级文件夹和游客云盘列表的读取方式，明确链接列表何时公开、何时接受游客会话。约定稳定的资源、文件和文件夹 ID，父子关系与路径，分页游标和结束标记，以及已保存、无权限、资源过期或删除等状态。请明确列表中文件和文件夹分别允许哪些操作。

## 2. 预览、保存、上传、下载与删除

- 提供文件名称、类型、字节大小、缩略图及视频时长等列表信息。说明图片和视频预览地址的鉴权、有效期、刷新方式及支持格式。免费用户保存到网盘后才可预览分享中的图片或视频，会员可预览未保存的图片或视频。其他类型不提供预览。请分别返回可预览、需先保存、锁定及不支持预览等可区分的结果。
- 提供从分享链接直接保存、从设备选择文件上传、下载和删除的接口。说明上传会话、大小与格式限制、完成确认，以及提交后怎样获取云盘文件记录和最新用量。请明确上传中断、提交失败、重复请求及多个设备同时保存或上传的处理方式。成功应由服务端确认，同一操作重试不得重复存入或计入用量。
- 说明下载地址的签发、有效期和刷新方式。预览、下载等操作统一校验当前文件权限。请区分云端容量不足、链接失效、游客会话失效、文件锁定等可由服务端判断的失败原因，便于 App 显示对应提示。

## 3. 容量、激励广告与会员

- 提供账号容量快照，包含基础容量、订阅容量、临时容量、有效总容量、已用和可用空间、当天扩容是否可领、服务端当前时间及下次重置时间。容量用字节返回，请确认 GB 和 TB 的换算口径。免费账号基础容量 **5 GB**，每账号每天完整看完一次激励广告可领取 **2 GB** 临时容量。临时容量及当日领取状态在服务端每日 **00:00 UTC（香港时间 08:00）** 重置。
- 提供可领取判断、广告完成校验、发放确认及结果查询方式。请说明凭据和账号如何绑定，以及重复回调、重复请求或跨设备并发怎样保证只发一次。无广告、未看完或校验失败不发容量。云端容量不足时，请返回当日能否领取，供 App 显示「观看广告扩容」与「开通会员」，用完后只显示会员入口。
- 提供 StoreKit 商品及经验证的交易与游客 `userId` 的绑定规则，以及购买、恢复、订阅到期后的权益刷新契约。订阅权益按设计稿为 **10 TB** 云端容量、免广告、直接预览分享链接中尚未保存的图片和视频。请说明恢复购买时如何认领权益、权益何时生效，以及容量变化后怎样读取最新文件状态。

## 4. 文件锁定与 72 小时清理

- 云文件需能区分分享链接保存与设备上传，并返回保存或上传完成时间、文件大小、锁定状态及连续锁定起点。请约定完成时间相同时的稳定顺序。容量下降时按完成时间从早到晚累计，遇到第一个放不下的文件后，它和后面的文件全部锁定。锁定文件仍占空间，只能删除。
- 删除、扩容或订阅生效后，由服务端重新计算并返回用量、锁定与解锁结果。分享来源文件连续锁定 **72 小时**后，从云盘移除并释放容量，保留原链接记录。刷新页面或自动续会话后延续同一个锁定起点。请返回移除状态和可用于再次保存的来源标识。链接仍有效且容量足够时可再次保存。设备上传的云文件继续锁定，直至用户删除或容量恢复。

## 5. 插页广告配置

- 开屏、激励和插页广告联调采用 Google 官方 iOS 测试配置。正式切换时再提供 App ID、各格式的独立广告位、开关及字段含义。
- App 沿用 UMP 的广告请求门控和会员免广告规则，预加载 **1 条**插页。免费用户在云端保存成功，以及视频播放返回文件夹时检查是否展示，两处共用 **2 分钟**最小间隔。无可用广告或间隔未到立即跳过，保存和返回正常完成。云端保存事件等接口确认成功后接入。

## 请随接口文档提供的联调样例

1. 一条包含子文件夹、图片、视频和其他格式的有效分享链接，以及一条已失效链接。提供免登录浏览、自动取得或更新游客会话后直接保存的响应样例。
2. 免费和会员游客身份各一份，可复现保存成功、上传失败后重试、云空间不足、锁定下载被拒，以及免费和会员的预览差异。加入会话过期、续会话和恢复购买的样例，检查权益与文件归属。
3. 容量样例可复现重复广告回调、香港时间 08:00 重置及订阅到期。准备一组「较早的大文件放不下、之后的小文件本可放下」的数据，验证两者均锁定。
4. 分享来源和设备上传各准备一个已长期锁定的云文件，便于核对 72 小时清理、历史保留、容量释放及再次保存。另提供可验证插页广告两处触发共用间隔的联调配置。

正式切换前请另行确认生产 API 地址、分享域名、正式广告配置、正式订阅商品、官网、隐私政策和使用条款地址。
