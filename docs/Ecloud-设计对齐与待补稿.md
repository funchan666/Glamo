## 本轮已落地

- 确认、输入、导入来源及文件更多菜单使用居中悬浮玻璃。确认弹窗按画板的 376 点宽、32 点圆角和 48 点胶囊按钮排版，小屏随容器收窄。系统文件、相册、Apple 购买管理和分享使用系统界面。订阅、导出和协议阅读使用独立页面。
- 主背景采用 `#F2F1F7`，主强调色采用 `#0082FB`。iOS 26 及以后，浮层和列表分组等卡片使用 SwiftUI 原生 Liquid Glass。镂空底栏保留透明边缘，只有选中项下方的透明玻璃随切换滑动，图标和文字独立绘制。页面可滚到栏后，末项按栏与小窗的实测高度留白。iOS 17 至 25 使用系统 Material。 [Apple Liquid Glass 文档](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)
- 换入稿内 1024 × 1024 云朵回形针 App Icon、启动标识、蓝色文件夹和时钟缺省图、三个底栏图标，以及播放器双箭头图标。设计截图与下载参考图未加入应用资源。
- 本机视频默认打开沉浸播放器；视频填满播放区，中央为快退／播放暂停／快进，进度和设置留在底部，返回入口留在顶部。保留既有队列和播放引擎。
- 暂停编辑入口及相册导入后自动打开编辑器；MP4／M4A 导出、取消导出、导出结果和系统分享仍走原实现，导出页面不显示裁剪等编辑工具。
- 文件、文件夹的新建、重命名、移动、删除沿用原库操作；接口文件夹封面优先与默认图回退仍保留。观看／收藏额度、激励广告、购买／恢复及权限配置未重写。
- 搜索页首先显示历史；无历史时使用新稿的链接缺省图。没有匹配结果时显示放大镜插图和「清除搜索」；网络搜索仍保留「搜索网页」入口。文件导入和新建保留在文件页，Plus 入口保留在我的页和导出流程。
- 搜索和网络文件夹加载失败使用新稿的连接异常插图、具体失败原因及原有「重试」。加载更多失败时保留已显示的列表。
- 传输页换入新稿的上传／下载托盘插图，区分不同筛选条件的缺省说明，保留原导入、下载、导出记录及筛选逻辑。
- 横屏播放器按稿完整显示视频比例，保留中央播放控件、顶部返回和底部进度条。倍速和画质面板竖屏贴底、横屏靠右，随进度条高度留出空间，选择高亮。网络播放器保留手动选择的填充／适应方式，大字号和矮屏可滚动。
- 「我的」按稿排列账户、空间与 Plus，以及四项菜单。会员页展示三项首版权益、StoreKit 实际价格和固定底部的订阅按钮。账户页显示本机实际用量及云盘开放说明。

## 已补的交互稿

[打开 Ecloud 首版交互补稿](Ecloud-首版交互补稿.html)。可按场景查看分享、直接保存、预览、容量、会员、传输及文件操作，支持横屏和大字号。沿用原稿的蓝色重点、浅色底、居中毛玻璃弹窗及悬浮底栏。分享列表免登录，点保存后留在原列表等待服务端确认。云盘及套餐权益为设计示例，正式价格和权益分别由 StoreKit 与服务端确认。原 Figma 文件当前只有查看权限，补稿以本地页面交付。

| 出现的时候 | 请补的画面和按钮 |
| --- | --- |
| 视频还没播出来、卡住、打不开或播完了 | 分别显示什么提示；「重试」「重新播放」「下一条」放哪里；没有下一条时怎么显示。横屏也请给对应画面。 |
| 从播放列表换到另一个视频 | 新文件名、加载提示、当前播放标记怎么显示；列表很长时，怎样找到正在播放的那一项。 |
| 正在导入、下载或导出视频 | 百分比、速度或文件大小放哪里；暂停、继续、重试和取消按钮怎么放；成功、失败、取消后分别显示什么。 |
| 导出后分享文件，或从 iOS 分享面板返回 | 「准备分享」「分享完成」「取消分享」「分享失败」四种提示，以及「再次分享」按钮的位置。 |
| 文件名没填、重名、不能移动，或文件夹有内容 | 错误提示放在输入框哪里，确认按钮是否可点；键盘弹出、小屏、大字号和很长文件夹路径时怎么排。 |
| 云端扩容广告、购买或恢复还没完成 | 广告加载、无广告、未看完、容量到账／失败、价格加载及购买／恢复结果。会员稿使用 10 TB、免广告、未保存预览三项首版权益。 |
| 从分享列表点保存 | 在原文件夹显示保存确认中，按服务端结果显示保存成功、失败可重试或云空间不足。 |
| 打开图片，或链接文件因连续锁定被移除 | 图片预览的加载、失败、缩放和关闭；文件移除后链接记录放哪里，以及如何再次保存。 |

原生 App 已补上本机和链接视频的加载、缓冲、播完以及本机队列位置，传输页展示已有离线下载任务，文件和导出结果补齐失败、取消和再次分享，识别设备空间不足后显示专用提示。购买页增加实际价格加载及恢复购买反馈。首版沿用后台自动建立的游客会话。直接保存、实时容量、云端上传与预览权限等待 [后端对接材料](Ecloud-后端对接清单.md)。

## 核对边界

此前已在浏览器查看补稿的横屏大字号播放器和扩容到账场景。本次对 64 个交互场景、直接保存的按钮去向、会员文案、原素材引用及文档链接做静态核对。

本轮检查源码语法、资源引用、配置和改动差异。按要求跳过编译和测试。实际设备的玻璃渲染、小屏和横屏摆放、像素对照及云盘服务联调待验收。

渐变文件夹、删除和传输图标暂用项目内现有图标。套餐选中态暂用圆形指示器，设计稿中的勾选图标需要独立素材。
