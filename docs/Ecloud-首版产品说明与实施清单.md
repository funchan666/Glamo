# Ecloud 首版产品说明与实施清单

> **Execution:** 按用户授权和现有原生架构实施；接口未提供的部分保留为明确待接项，不编造服务端状态。

按 Figma 首版产品说明完成网盘。沿用 SwiftUI、AVFoundation、StoreKit 购买／恢复及 UMP。云文件、用量、奖励和锁定由服务端按游客身份管理，本机文件库继续独立。

用户最新确认首版免登录，和现有体验一致。浏览、保存和上传走自动游客会话。云盘能力属于首版必做，当前等待云盘接口。

## 产品约定

- 分享列表及保存沿用自动游客会话。会话到期由 App 自动恢复，用户直接操作，不显示注册或登录页面。
- 免费基础容量 **5 GB**；完整观看激励广告可领取 **2 GB** 临时容量，每账号每天 **1 次**。
- 临时容量与领取次数在服务端每日 **00:00 UTC** 重置，即香港时间 **08:00**。
- 订阅权益按设计稿为 **10 TB** 云端容量、免广告、直接预览分享链接中尚未保存的图片和视频。权益由服务端确认。
- 开屏、激励和插页广告联调采用 Google 官方 iOS 测试配置，正式广告配置后续替换。广告继续遵循 UMP 和会员免广告规则。
- 首版不开放创建分享链接；系统分享本机文件与创建网盘分享链接是两种操作。
- 图片和视频以外的格式不提供预览；本机导入不等于云端上传，收藏／离线下载不等于保存到账号网盘。
- 保留已有本机视频、索引、权限和购买／恢复实现，不用旧数据清理来完成迁移。
- 默认不编译、不测试、不运行应用或模拟器；静态结果不代表云端功能已接通。

## 首版功能标准

| 场景 | 首版应有行为 |
| --- | --- |
| 打开分享链接 | 外部链接唤起 App 与 App 内搜索粘贴链接，进入同一份资源内容页；先显示列表。 |
| 免登录浏览与保存 | 用户打开链接即可浏览，点「保存」直接提交。App 自动获取或续接游客会话，云端由其服务端身份确定归属。 |
| 免费用户预览 | 链接中的图片和视频先保存到云盘，再允许预览。 |
| 订阅用户预览 | 可直接预览链接中尚未保存的图片／视频。 |
| 上传或保存 | 由服务端确认容量和操作结果；完成后刷新列表和用量。设备空间不足与云端容量不足分别提示。 |
| 云端容量不足 | 当天还能领取临时容量时，显示「观看广告扩容」和「开通会员」；领取次数用完后只显示会员入口。 |
| 容量缩减 | 临时容量失效或订阅到期后，按保存／上传完成时间从早到晚累计。遇到第一个放不下的文件后，它及之后的文件全部锁定，不能跳过大文件后继续纳入小文件。 |
| 锁定文件 | 仍占用空间，文件操作只允许删除。删除、获得临时容量或开通订阅后重新计算，可容纳的文件立即解锁。 |
| 链接文件连续锁定 72 小时 | 服务端从账号网盘移除文件并释放容量，保留链接记录。链接有效且容量足够时可再次保存。 |
| 本地上传文件超额 | 保持锁定，等待用户删除或容量恢复；不套用链接文件的 72 小时移除规则。 |
| 插页广告时机 | 免费用户保存成功，以及从视频播放返回文件夹时，判断是否展示。两个时机共用 **2 分钟**最小间隔。 |
| 插页广告无填充或未到间隔 | 提前预加载 **1 条**；没有可用广告或未到间隔就跳过，操作正常完成。订阅用户免广告。 |

## 目前代码与首版的差异

已对照 Vistream 当前原生版。Vistream 使用游客会话获取分享资源和分页目录，把收藏下载成设备离线副本。Ecloud 的账号归属、云端上传、容量、锁定及预览权限仍需独立的云盘接口。

| 项目 | 当前实现 | 后续接入位置 |
| --- | --- | --- |
| 链接进入列表 | 已有搜索结果、文件夹浏览和 URL Scheme 基础；真实匿名契约与分享域名关联待确认。 | `Glamo/App/GlamoApp.swift`、`Glamo/Features/LinkedVideoView.swift`、`Glamo/Features/SavedLibraryViews.swift` |
| 游客身份与云盘 | `APIClient` 已有自动游客会话、视频资源读取及购买服务。云盘文件归属、列表、保存和上传等待后端契约。 | `Glamo/Core/APIClient.swift`、`Glamo/Core/LessonContracts.swift` |
| 保存与本地上传 | 收藏会建立离线下载任务，系统导入建立本机副本。云端保存和上传待接入。 | `Glamo/Core/VideoLibraryParity.swift`、`Glamo/Core/LibraryStore.swift`、`Glamo/Core/OfflineVideoCache.swift` |
| 预览与格式 | 当前主要处理视频与音频文件，以及观看和收藏额度。云盘图片预览及首版预览权限待接入。 | `Glamo/Features/LinkedVideoView.swift`、`Glamo/Features/DriveBrowser.swift` |
| 额度与重置 | `QuotaStore` 统计观看／收藏次数，并按设备本地 05:00 重置；这套机制不是首版容量账本。 | `Glamo/Core/QuotaStore.swift`、`Glamo/Features/MembershipView.swift` |
| 容量与锁定 | 没有服务端用量、临时容量、锁定状态和 72 小时清理结果。现有设备占用不能显示为云端用量。 | 待云盘接口映射后接入文件列表、空间卡、更多菜单及播放器。 |
| 广告 | 开屏、激励和插页均配置 Google 官方 iOS 测试位。网络文件夹返回已接预载插页检查，云端保存成功后的触发依赖保存接口。 | `Glamo/Core/RewardedAds.swift`、`Glamo/Features/SavedLibraryViews.swift` |
| 购买和恢复 | 保留原 StoreKit 与服务端权益校验。10 TB 的分配、到期和恢复后的容量变化还需云盘服务确认。 | `Glamo/Core/CommerceStore.swift`、`Glamo/Features/MembershipView.swift` |

## Review Focus

1. 旧观看／收藏次数与新云盘容量是不同的数据；接口切换不得重复扣费、重复发奖励或清掉本机文件。
2. 两台设备同时保存、领取奖励或跨 UTC 零点时，由服务端统一判定，客户端时间不能成为授予容量的依据。
3. 一个较早的大文件放不下时，之后的小文件也应锁定；锁定文件继续计入已用空间。
4. 刷新、重启和续会话后延续同一锁定起点。自动移除只针对达到条件的链接来源云文件。
5. 会员、UMP、广告加载失败或页面关闭时不阻塞文件操作；付费权益及广告扩容都要有服务端确认。

## 接口到位后的实施步骤

### 1. 接游客身份、链接资源和云盘

- [x] 已核对首版说明和目前接口能力，保留现有本机媒体。
- [ ] 按后端契约接入现有游客身份、列表与分页、保存、上传、下载和删除。确认会话过期自动恢复、重装或换机的文件归属及恢复购买后的权益。
- [ ] 将搜索与外部链接路由汇合到资源列表，通过游客会话直接保存。首版只接收已有分享链接。
- [ ] 云端文件使用服务端稳定 ID 和来源标记；原本机索引保持独立。
- 验收涵盖免登录浏览和直接保存、会话到期后恢复，以及服务端确认上传或保存成功后刷新文件列表。

### 2. 接容量、奖励与锁定

- [ ] 映射服务端时间、基础／临时／订阅容量、已用字节、奖励领取状态、文件锁定状态与连续锁定起点。
- [ ] 保存／上传前消费服务端容量判定，处理容量不足和并发冲突；不在本机虚构云端剩余容量。
- [ ] 完整观看广告后提交奖励凭据；服务端幂等确认后刷新临时容量。无广告、关闭或失败不发容量补偿。
- [ ] 所有锁定文件入口统一只允许删除；删除／奖励／订阅成功后刷新服务端快照。
- [ ] 展示服务端的解锁与 72 小时清理结果，保留链接记录；不在客户端启动计时器删除用户原视频。
- 验收：UTC 跨日、会员到期、大文件截断、连续锁定、重新保存和多设备并发均按上表执行。

### 3. 接预览与会员权益

- [ ] 免费未保存、免费已保存、会员未保存、锁定文件和不支持的格式分别按服务端权限进入对应提示或预览。
- [ ] 加入图片预览，视频继续使用原生播放引擎；原购买／恢复继续由 StoreKit 和服务端校验共同完成。
- [ ] 套餐权益和七种语言按设计稿对齐。正式销售以 10 TB 容量、免广告、未保存图片和视频预览已实际可用为前提。
- 验收：不能靠缓存、离线文件路径或旧观看次数绕过云文件锁定；本机视频仍可按本机功能使用。

### 4. 接首版插页广告

- [x] 已配置 Google 官方 iOS 插页测试位并接入网络文件夹返回，沿用 UMP 的广告可请求状态。
- [ ] 正式切换时接入独立插页广告位及服务端配置。
- [ ] 在真实保存成功与播放器返回文件夹后触发判断，共用 2 分钟最小间隔；预加载一条，无可用广告立即跳过。
- [ ] 在广告占用、后台切换、订阅生效和页面退出时保持操作结果和原播放／返回状态。
- 验收：两种触发交替发生仍共用间隔；广告不展示不影响保存、返回或后续播放。
