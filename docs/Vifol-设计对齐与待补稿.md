## 本轮已落地

- 应用内确认、输入、导入来源、文件更多、倍速、分辨率等弹窗采用居中悬浮玻璃容器；系统文件／相册选择器、Apple 购买管理和系统分享面板保留真实系统流程。订阅、导出和协议阅读作为独立页面。
- 主背景统一为稿内 `#F2F1F7`，主强调色为 `#0082FB`；列表分组、个人页和会员卡片共用毛玻璃材质。按后续最新要求，底栏改为镂空悬浮：保留透明细边缘，只在选中位置显示会滑动的玻璃块；页面可滚到栏后，末项按栏与小窗的实测高度留白。
- 换入稿内 1024 × 1024 云朵回形针 App Icon、启动标识、蓝色文件夹和时钟缺省图、三个底栏图标，以及播放器双箭头图标。设计截图与下载参考图未加入应用资源。
- 本机视频默认打开沉浸播放器；视频填满播放区，中央为快退／播放暂停／快进，进度和设置留在底部，返回入口留在顶部。保留既有队列和播放引擎。
- 暂停编辑入口及相册导入后自动打开编辑器；MP4／M4A 导出、取消导出、导出结果和系统分享仍走原实现，导出页面不显示裁剪等编辑工具。
- 文件、文件夹的新建、重命名、移动、删除沿用原库操作；接口文件夹封面优先与默认图回退仍保留。观看／收藏额度、激励广告、购买／恢复及权限配置未重写。

## 请设计师补齐

目前查看到的 APP UI 画板提供常规竖屏页面和部分弹窗；下列状态尚未看到对应设计帧：

| 范围 | 需要的设计 |
| --- | --- |
| 播放器适配 | 横屏、小屏、大字号；长标题；快退／快进的提示方式；返回小窗入口在这些状态下的位置 |
| 播放器状态 | 首次加载、缓冲、播放失败与重试、播放结束；上一条／下一条切换；长队列与当前项定位 |
| 搜索与文件库 | 搜索中、无结果、接口失败／重试、加载更多；空的嵌套文件夹及长路径 |
| 传输与导出分享 | 导入／下载进度、暂停与失败；MP4／M4A 导出过程、取消、失败、成功及分享完成／取消／失败 |
| 确认与输入 | 重名、空名称、不可用操作、非空文件夹删除说明；键盘弹出和大字号版本 |
| 会员与广告 | 与真实观看／收藏／导出权益一致的会员稿，价格加载与失败、购买／恢复结果；额度不足、广告准备中和无广告可用 |

未提供的新状态暂用同一套玻璃组件承接现有真实交互。活动页没有独立缺省插画稿，暂复用稿内时钟；请补充专用稿或明确复用范围。稿内“10 TB 云空间”等示例权益不代表当前本地文件库的真实服务，未写入会员承诺。
